# Declared differences between the Forge tree and the Ornithe tree.
#
# Transitional: this pair exists only while both trees do, and this file is
# deleted with the Forge tree (P10). It records what the port deliberately
# changed; tools/forge-port-base.txt separately catches Forge edits made after
# the port, including edits inside the files declared divergent here.
#
# Checked by tools/check-tree-drift.sh, but only while the Ornithe tree exists
# (ornithe/src on disk or in the index). Until then this file must hold no
# entries. Once it exists, anything NOT declared here must be byte-identical in
# both trees, or the check fails; an empty manifest is refused.
#
# Format (whitespace separated, `#` starts a comment):
#
#   divergent <tree> <path>          - present in both trees, allowed to differ
#   one-sided <tree> <side> <path>   - present on <side> only
#
#   <tree> = main | test | res  <side> = forge | ornithe
#   main = src/main/java       vs ornithe/src/main/java
#   test = src/test/java       vs ornithe/src/test/java
#   res  = src/main/resources  vs ornithe/src/main/resources
#   <path> is package-relative for main and test, e.g.
#     com/bedwarsqol/gui/SettingsGui.java, and relative to the resources root
#     for res, e.g. mcmod.info
#
# Entries are validated in both directions, exactly as in
# tools/tree-divergence.txt: a `divergent` entry whose copies are identical, or
# (java) differ only in comments or whitespace, fails; a `one-sided` entry that
# is in both trees, on the wrong side, or in neither fails. Stale entries are
# errors, not noise.
#
# Give each group of entries a comment saying WHY the trees differ.

# ---------------------------------------------------------------------------
# divergent: same path in both trees, contents legitimately differ
