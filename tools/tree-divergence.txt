# Declared differences between the Forge tree and the Lunar tree.
#
# Checked by tools/check-tree-drift.sh. Anything NOT declared here must be
# byte-identical in both trees, or the check fails.
#
# Format (whitespace separated, `#` starts a comment):
#
#   divergent <tree> <path>          - present in both trees, allowed to differ
#   one-sided <tree> <side> <path>   - present on <side> only
#
#   <tree> = main | test        <side> = forge | lunar
#   <path> is package-relative, e.g. com/bedwarsqol/gui/SettingsGui.java
#
# Entries are validated in both directions. A `divergent` entry whose two copies
# have become identical fails, as does a `one-sided` entry that appears in both
# trees, on the wrong side, or in neither. Stale entries are errors, not noise -
# a manifest nobody prunes stops being a safety net.
