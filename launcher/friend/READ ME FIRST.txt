COBBLIFY FOR LUNAR CLIENT AND FORGE - macOS
===========================================

Cobblify works with Lunar Client and with a Prism Launcher Minecraft
1.8.9 + Forge 11.15.1.2318 instance. You can have both. If you only use
one, the other is skipped.

You only do this once.


1. INSTALL
----------

Drag "Cobblify Launcher.app" into your Applications folder.

Do NOT run it from your Downloads folder or from a temporary folder -
move it to Applications first, or it may fail to start.


2. FIRST OPEN - macOS WILL BLOCK IT
-----------------------------------

Cobblify isn't signed with a paid Apple developer certificate, so macOS
stops it the first time. This is normal. It is not a virus warning -
macOS says this about every app that hasn't paid Apple's yearly fee.

Double-click the app. You'll get a message saying macOS "cannot check it
for malicious software". Click Done / Cancel, then:

    Apple menu > System Settings > Privacy & Security
    scroll down to Security
    next to "Cobblify Launcher was blocked", click  Open Anyway
    confirm with your password or Touch ID

The app opens. You never have to do this again.

NOTE: On older Macs people used to right-click an app and choose Open.
Apple removed that in macOS 15, so use the System Settings steps above.


3. WHAT IT DOES
---------------

Open Cobblify Launcher and press Choose Your Setup, then pick Lunar
Client or Prism Launcher. If the one you pick isn't on this Mac yet,
Cobblify opens its download page and starts setup by itself once it's
installed.

LUNAR: Lunar has to have been signed in once. If it hasn't, Cobblify
stops at "Sign in to Lunar" - press Open, sign in, and setup goes on.
If Lunar is open, Cobblify closes it itself ("Closing Lunar") before it
changes Lunar's settings, then finishes.

PRISM: Cobblify lists the Prism instances that can run Cobblify; pick
one and press Set up Prism. With none, it makes a 1.8.9 instance for
you, downloading Java 8 and Minecraft 1.8.9 if it has to. Prism needs
a Microsoft account signed in first.

You can add the other client later from the arrow next to Launch.

Then press Launch Cobblify. The game starts with Cobblify; you join
Hypixel yourself. Cobblify never hides Lunar's or Prism's windows:
Lunar hides its own window when the game starts and shows it again
when the game closes. Lunar keeps running afterwards, which is normal.

When you close the game, Cobblify comes back to Launch, so you can
launch again any time. (With External Overlay off in Settings, Cobblify
quits itself once the game has loaded instead.)

The very first time, Lunar may ask you to log in or update - that
window is real, use it like you always do.


4. IN GAME
----------

  - Cobblify only works on Minecraft 1.8.9. If Lunar is on another
    version, Cobblify stops at "Set Lunar to 1.8.9" - press Open, pick
    1.8.9 in Lunar, and launch again.
  - press RIGHT SHIFT in game to open Cobblify's settings

Prism has the same loading updates and live lobby/queue/game dashboard
as Lunar.

IMPORTANT: turn Lunar's "Waypoints" module OFF in the settings profile
you actually play on. Leaving it on can make Cobblify's stats go
missing. This is per-profile, so if you switch profiles, check again.


5. IF SOMETHING GOES WRONG
--------------------------

Repair
    Shown after a Cobblify update while Lunar is open: Cobblify's files
    in Lunar need updating. Press it; Cobblify closes Lunar, updates
    them and you're back at Launch.

Try again (setup didn't finish)
    Close the game if it's open, then press Try again. Setup runs
    again.

"Cobblify didn't load"
    Minecraft started without Cobblify. Press Try again. If it keeps
    happening on Lunar, press Repair in Settings; then message Jacob.


6. UNINSTALLING
---------------

The launcher saved a copy of your Lunar settings before touching
anything. To undo everything it changed, paste this into Terminal:

    cp ~/.lunarclient/settings/launcher.json.bak-cobblify \
       ~/.lunarclient/settings/launcher.json

Then delete Cobblify Launcher.app, and delete the ~/.weave folder if you
don't use any other Weave mods.

For Prism, delete the Cobblify jar out of your instance's "mods" folder,
or delete the instance Cobblify made. You can also delete ~/.cobblify,
which is where its settings and its note of which instance you chose
are kept.
