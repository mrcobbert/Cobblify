COBBLIFY FOR LUNAR CLIENT AND FORGE - Windows
=============================================

You only do this once.

Cobblify works with Lunar Client and with a Prism Launcher Minecraft
1.8.9 + Forge 11.15.1.2318 instance. You can have both. If you only use
one, the other is skipped.


1. INSTALL
----------

Unzip the whole "Cobblify (Windows)" folder anywhere you like
(Desktop, Documents, wherever). Keep the folder together -
"Cobblify Launcher.exe" needs the "resources" folder sitting
next to it.


2. FIRST OPEN - WINDOWS WILL BLOCK IT
-------------------------------------

Cobblify isn't signed with a paid Microsoft certificate, so Windows
shows a blue "Windows protected your PC" screen the first time. This is
normal - Windows says this about every app that hasn't paid for a
certificate.

On that screen:

    click  More info
    then   Run anyway

You never have to do this again.


3. BEFORE THE FIRST RUN
-----------------------

If you use Lunar: open Lunar Client normally ONCE and log in, then quit
it. Cobblify registers itself with Lunar's own settings, so Lunar has to
exist before Cobblify can do that.

While you're in there: make 1.8.9 your selected version. The Launch
button starts whatever version Lunar has selected, and Cobblify only
works on 1.8.9.

If you use Forge: install Prism Launcher and make a Minecraft 1.8.9 +
Forge 11.15.1.2318 instance. Cobblify does not install Forge or create
the instance for you.


4. WHAT IT DOES
---------------

Quit Lunar Client first, then open Cobblify Launcher. It will:

  - install Cobblify and the Weave loader, and register them with Lunar
  - offer to set up Forge (see below)
  - say "Cobblify vX.X.X ready"

FORGE: Cobblify lists compatible Prism instances. Click Set up once;
afterward Launch Forge starts that instance, hides Prism and joins
Hypixel automatically.

It remembers your choice, so next time it just updates that folder.

If you already had an older Cobblify jar in there, it gets moved aside
rather than deleted - Forge refuses to start if two copies are present.
The launcher tells you the exact file and its new name.

Then click LAUNCH LUNAR. It should start the game and join Hypixel by
itself.

Lunar's own windows get minimized out of the way while the game boots.
If one of them is a window you actually want (see below), just restore it
from the taskbar - Cobblify stops touching a window after a moment and
leaves it wherever you put it.

The very first time, Lunar may ask you to log in - that window is real,
log in like you always do. Same goes for Lunar updates. If it gets
minimized while the game is starting, click it in the taskbar and it
stays open.

The button works once per open. To launch again later, reopen Cobblify -
or just start Lunar normally; Cobblify should load either way, you only
miss the auto-join.


5. IN GAME
----------

  - press RIGHT SHIFT in game to open Cobblify's settings

Launch Forge has the same loading updates and live lobby/queue/game
dashboard as Launch Lunar.

IMPORTANT: turn Lunar's "Waypoints" module OFF in the settings profile
you actually play on. Leaving it on can make Cobblify's stats go
missing. This is per-profile, so if you switch profiles, check again.


6. IF SOMETHING GOES WRONG
--------------------------

"Quit Lunar"
    Lunar is still running. Quit it fully, then reopen the launcher.
    Lunar overwrites its own settings when it closes, so Cobblify waits
    rather than fighting it.

    Closing the Lunar window is often NOT quitting it. Lunar can be set to
    start with Windows and sit in the system tray, where it keeps running
    with no window at all. Click the ^ arrow next to the clock, right-click
    Lunar Client, and choose Quit. If you would rather it stopped doing
    that, turn off "Start with computer" in Lunar's settings.

"Conflicting jars", or a message about another Cobblify jar
    You have more than one copy installed. The launcher lists them and
    will not delete anything it isn't certain it put there. Remove or
    rename the extra one, then reopen the launcher.

    On Forge this matters more than it sounds: the game will not start
    at all with two copies of the same mod.

I want a moved-aside jar back
    Anything the launcher set aside is still there, in the same folder,
    with ".cobblify-disabled" added to the end of its name. Delete that
    bit from the name and it's exactly as it was. (Nothing is ever
    deleted, so you can always get it back.)

"This copy is incomplete"
    The download didn't finish or got corrupted. Download it again.

Any message that mentions "launcher.json"
    Take a screenshot and send it to Jacob. This is the launcher being
    careful with Lunar's settings file rather than guessing - nothing
    on your machine was changed.

The app opens but nothing happens in game
    Make sure 1.8.9 is your selected version in Lunar, and that you
    quit Lunar completely before running the launcher the first time.


7. UNINSTALLING
---------------

The launcher saved a copy of your Lunar settings before touching
anything. To undo everything it changed, paste this into
Command Prompt (Win+R, type cmd, Enter):

    copy /Y "%USERPROFILE%\.lunarclient\settings\launcher.json.bak-cobblify" "%USERPROFILE%\.lunarclient\settings\launcher.json"

Then delete the "Cobblify (Windows)" folder, and delete the
%USERPROFILE%\.weave folder if you don't use any other Weave mods.

For Forge, delete the Cobblify jar out of your instance's "mods"
folder - the launcher showed you exactly where it put it. You can also
delete %USERPROFILE%\.cobblify, which is where its settings and its
note of which folder you chose are kept.
